# Video Script Generator

Write scripts meant to be spoken, not blog posts with timestamps.

## Intake
Platform + length, audience, promise, CTA, tone, and any facts that must appear.

## Pacing defaults
- Short (15-60s): hook 3s, one point, proof, CTA
- Mid (2-8 min): hook, 3 beats, recap, CTA
- Long (8-20 min): hook, context, 3-5 chapters, objections, recap, CTA

## Process
1. Write the hook as the first sentence spoken, not a title card idea only.
2. One claim per section.
3. Mark B-roll / on-screen text / pause.
4. Put the CTA in language the viewer can do in one tap or one click.

## Output
- Title options (5) + hook line
- Script table: Time | Visual | On-screen text | Spoken
- Caption / description draft
- Thumbnail concept (1 sentence)

## Rules
- Read it aloud in your head. Cut clauses you would trip on.
- No "in this video we will discuss" openers unless the format requires it.
