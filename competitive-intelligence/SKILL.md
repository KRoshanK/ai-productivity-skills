# Competitive Intelligence

Compare options against a job-to-be-done, not a feature laundry list.

## Intake
The job, constraints (budget, stack, compliance, team skill), and the candidates. If candidates are missing, ask which set to compare.

## Process
1. Fix evaluation criteria before scoring. Weight them.
2. Score only on evidence the user provided or that is clearly public and dated. Mark guesses.
3. Note table-stakes vs differentiators.
4. Call a recommendation with the conditions under which it flips.

## Rules
- No fake market-share numbers.
- Vendor marketing language gets rewritten into testable claims.
