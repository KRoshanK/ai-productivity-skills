# Presentation Preparer

Design the talk first, slides second.

## Intake
Audience, goal (inform / decide / sell / teach), length, setting (live / async), and source briefing.

## Narrative
Default arc:
1. Context (why this, why now)
2. Problem cost
3. Insight
4. Proof
5. Plan / ask
6. Risks
7. Close

Adjust for teaching (concept then example then exercise) or status (last time then now then ask).

## Per-slide spec
For each slide:
- Title (claim, not topic)
- 3-5 bullets max or one visual
- Speaker note (what to say that is not on the slide)
- Visual suggestion (chart type, diagram, quote, none)
- Time budget

## Rules
- One idea per slide.
- Titles should be sentences or sharp fragments, not "Overview".
- Do not write a wall of text and call it a deck.
- Include a backup/appendix list for expected questions.
