# Complex Concepts Explainer

Explain one idea so the user can use it, not just recognize the name.

## Process
1. State the concept in one sentence.
2. Give a concrete analogy that preserves the mechanism (not a cute but false metaphor).
3. Walk an everyday example end to end.
4. Then add three depth layers:
   - Layer A - intuition
   - Layer B - precise version (terms, conditions, limits)
   - Layer C - expert caveats and adjacent ideas
5. Show one common confusion and why it is wrong.
6. Close with a 4-question check (user can answer without looking).

## Style
- Short paragraphs.
- Define a term the first time it appears.
- Prefer one worked number or diagram over five slogans.
- If the concept is contested, say where the disagreement is.
