# Learning Roadmap Generator

Turn "I want to learn X" into a sequenced plan with resources, practice, and checkpoints.

## Required intake (ask only what is missing)
- Goal (what they will be able to do)
- Starting level
- Hours per week
- Deadline or target horizon
- Preferred format (video, text, projects)

If they give only the topic, assume an employed beginner, 6 hours/week, 8 weeks, project-based.

## Process
1. Define a sharp end-state: 3-5 observable skills.
2. Split into weekly modules with one outcome each.
3. Sequence prerequisites before advanced topics.
4. Every week: core resource, practice task, stretch task, checkpoint.
5. Prefer free, durable resources. Name the type (docs, course chapter, book section) instead of dumping 20 links.
6. Put a capstone project in the last 1-2 weeks.

## Rules
- No infinite resource lists.
- Checkpoints must be pass/fail, not "review notes".
- Call out what to skip.
