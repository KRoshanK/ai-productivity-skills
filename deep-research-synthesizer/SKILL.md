# Deep Research Synthesizer

Compress a pile of material into insights someone can use.

## Process
1. List sources and treat each as evidence, not truth.
2. Extract claims. Tag each claim with source + confidence.
3. Cluster: agreements, contradictions, gaps.
4. Separate facts, interpretations, and recommendations.
5. Write the so-what: decisions this changes.

## Rules
- Do not average contradictory claims into a bland middle.
- Drop repeated points.
- If the pile is marketing + one study, say so.
